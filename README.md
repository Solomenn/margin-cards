# Margin Cards

在 Obsidian 里做类 MarginNote 的读书工具，电脑和 iPad 都能用。

## 现在有的功能（0.2.0）

- 右键文件列表里的 PDF → "用卡片模式打开"，在新标签页里用插件自己的 PDF 视图阅读。
- 只画屏幕附近的页，滚出去的页立刻释放画布，300 页以上的书也不占满内存。
- 缩放：工具栏的放大、缩小、适应宽度；Ctrl+滚轮；iPad 上双指捏合。
- 跳页：在页码框里输入页码，按回车。
- 目录：点左上角的目录按钮，点条目跳到对应页。
- 关掉再打开，回到上次的页码和缩放。
- 框选做卡片：点工具栏的裁剪图标，在页面上拖出一个框，松开后在小窗里选类型（摘录 / 错题）、颜色（红橙黄绿青紫，可不选）、分类（选已有的或输入新的），点确定。电脑上鼠标和笔拖动是画框；iPad 上笔画框、手指滚动。
- 每张卡片是库里的一个笔记：卡片/<PDF 名>/<卡片 id>.md，框里的内容存成图片 卡片/<PDF 名>/图片/<卡片 id>.png。笔记属性有：卡片类型、pdf、page、rect、颜色、分类、创建时间。
- PDF 上每张卡片画一个半透明的框，颜色跟卡片的颜色，没选颜色的是灰色；点框打开卡片笔记。
- 卡片笔记里点"回到原文"，PDF 跳到那一页，闪一下那个框。
- 卡片文件夹下自动生成 错题.base，列出所有错题的颜色、分类、页码；用 Bases 自带的筛选按颜色、分类筛选。
- 设置里可以改卡片文件夹的名字（默认"卡片"）。

## 安装

把 margin-cards-<版本>.zip 里的 main.js、manifest.json、styles.css 放进库里的 .obsidian/plugins/margin-cards/，重启 Obsidian，在"第三方插件"里启用 Margin Cards。

## 开发

```
npm install
npm run build
```

构建后生成 main.js。manifest.json 里的 version 和 package.json 里的 version 保持一致，每次发布的 zip 文件名带这个版本号。

## 路线

1. 自己的 PDF 视图（已完成）
2. 框选生成卡片，标颜色和分类（已完成）
3. 卡片进脑图（Canvas），左右并排、双向跳转
4. 卡片背面手写
5. 翻卡复习；回忆模式：在脑图里隐藏卡片内容，先想再看
6. 书本留白：在 PDF 两段之间撑开空白手写；显示方式有三种：嵌入正文、放在页边、收起成细线
7. PDF 手写图层：直接在 PDF 页面上手写，可一键显示或隐藏
